# Focus Preview 实测交接

> 当前已安装到本机 Epic `1.01.4b`（归档内部项目版本 `1.01.4`）。不需要再次运行安装器，直接从 Epic 正常启动游戏即可。

## 当前配置

- 基础速度：`1.5×`；
- 行动 Zoom：关闭；
- 未来永久金币：`2×`；
- Turbo：按住左 Shift，实际速度 `3×`；
- Focus：按住左 Ctrl，实际速度 `0.5×`；
- Focus 与 Turbo 同时按住时，Focus 优先。

## 第一轮：普通房间

1. 不按临时按键，确认仍是熟悉的基础 `1.5×`；
2. 按住左 Ctrl，确认游戏明显降到 `0.5×`；
3. 松开左 Ctrl，确认立即回到 `1.5×`；
4. 重复数次，留意是否漏输入、延迟恢复或卡在慢速；
5. 留意音效是否出现明显重叠、拉长或违和。

## 第二轮：Turbo 与 Focus 重叠

严格按以下顺序测试一次：

1. 按住左 Shift：应从 `1.5×` 变为 `3×`；
2. 不松 Shift，再按住左 Ctrl：应变为 `0.5×`；
3. Shift 仍按住，只松开 Ctrl：应恢复 `3×`；
4. 最后松开 Shift：应恢复 `1.5×`。

再反过来测试“先 Ctrl、后 Shift”。只要 Ctrl 仍按住，速度都应保持 `0.5×`。

## 第三轮：安全边界

分别在按住左 Ctrl 时尝试：

- 暂停并恢复；
- 切换房间或场景；
- Alt+Tab 到桌面后松开 Ctrl，再返回游戏；
- 返回菜单或读档（如正常游玩过程中方便遇到）。

每一种情况结束后都确认：游戏没有停留在 `0.5×`，Turbo 也没有意外保持开启。

## 第四轮：真实需求场景（可选）

不需要为了测试反复打到第四区域，也不要故意等到角色死亡。自动审计已经确认：

- 炸弹怪的 20 秒 Timer 随全局游戏时间缩放，Focus `0.5×` 下约为 40 秒；
- 玩家所称的手陷阱对应 `pieges - murs`，4.5 秒 Tween 完成后才触发致死，Focus `0.5×` 下约为 9 秒；
- 相对当前基础 `1.5×`，按住 Focus 后现实反应时间扩大为 3 倍。

如果正常游玩时自然遇到其中任一场景，只需顺手观察一次按下/松开是否舒服、音效是否异常，无需用死亡来证明判定。客观时钟链的验证依据见 [`20-hazard-timing-automation.md`](20-hazard-timing-automation.md)。

## 反馈格式

试玩后只需回答：

```text
普通房间按下/松开：正常 / 异常
Turbo + Focus 重叠：正常 / 异常
暂停、切场景、Alt+Tab：正常 / 异常
第四区域自然遭遇体验（可选）：舒服 / 异常（说明） / 未遇到
Ctrl 键位冲突：无 / 有（说明场景）
音频或其他问题：无 / 有（说明现象）
```

如遇到卡慢速或输入异常，先退出游戏，不要执行 Epic 验证文件；告诉 Codex发生场景。需要恢复原版时可在项目根目录执行：

```powershell
node tools\fast-cesto.mjs restore SolCesto backups\epic-1.01.4b
```
