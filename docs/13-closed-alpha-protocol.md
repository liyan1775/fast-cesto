# 公开 Alpha 执行与判定

> 当前状态：测试工具、预检、GitHub 反馈表单和候选包均已准备，改由公开仓库通过网络招募；真实的 3–5 台外部 Epic 环境结果尚未发生，不能由本机模拟替代。

## 1. 本轮目标

公开 Alpha 不再验证“功能是否原则上能做”，而是验证：

- 不同 Windows 与安装路径能否识别、安装和恢复；
- 普通玩家能否不使用命令行完成配置；
- 诊断报告是否足以定位问题且不暴露隐私；
- Turbo 和金币的剩余边界是否稳定；
- Node.js 前置条件是否构成明显阻碍。

## 2. 招募范围

首轮 3–5 名测试者，必须满足：

- 拥有 Epic Games Store 正版；
- 游戏界面版本为 `1.01.3`，且预检识别为受支持哈希；
- 能自行备份存档；
- 接受这是公开 Alpha，理解它尚未达到稳定版或公开 Beta 门槛；
- 愿意执行至少一次安装—启动—恢复往返并反馈。

优先覆盖矩阵：

| 变量 | 最小覆盖 |
|---|---|
| Windows | Windows 11 至少 2 台；Windows 10 至少 1 台 |
| 游戏路径 | Epic 默认、自定义含空格、非 ASCII 各至少 1 台 |
| DPI | 100%、125% 或以上各至少 1 台 |
| 安全软件 | Windows Defender 必测；第三方产品至少 1 台 |
| 存档状态 | 新进度、已有较长进度各至少 1 名 |

## 3. 测试材料

候选包内直接提供：

- `README.md`：安装和安全边界；
- `ALPHA-TESTING.md`：统一操作步骤；
- `FEEDBACK-TEMPLATE.md`：匿名化反馈格式；
- `KNOWN-ISSUES.md`：已知限制；
- UI 内 10 项兼容性预检和诊断下载。

测试者只需要提交模板和可选诊断 JSON；不得收集游戏资源、存档、Epic 配置或完整个人路径。

## 4. 问题分级

- **P0**：存档/游戏文件损坏、无法恢复原版、明显安全或隐私问题；立即停止测试；
- **P1**：受支持环境无法安装/启动，或核心功能导致流程阻断；暂停扩大发放；
- **P2**：单个功能、边界或兼容性异常，有明确恢复路径；记录并修复；
- **P3**：文案、布局、手感和易用性建议；进入常规排期。

## 5. Go / No-Go 门槛

进入公开 Beta 前至少满足：

- 3 台独立机器完成安装—启动—恢复，恢复成功率 100%；
- 未知或错误版本拒绝率 100%；
- 零 P0，未关闭的 P1 为零；
- 至少 2 次较完整 Run；
- 正常金币 2× 与至少一种死亡/特殊分支通过；
- Turbo 暂停、切场景和失焦在至少 2 台机器通过；
- 诊断报告无路径、账户、存档或游戏资源泄漏；
- Node.js 前置条件的失败率和反馈足以决定是否捆绑运行时。

在这些结果到齐前，项目状态保持“Public Alpha”，不能改称 Public Beta 或 Stable。
