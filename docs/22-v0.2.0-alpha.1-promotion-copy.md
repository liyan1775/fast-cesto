## Bilibili 专栏完整文案

### 标题

《寻日之旅》1.01.4b 加速 Mod 更新：新增按住 Ctrl 临时减速

### 正文

之前我为 Epic 版《寻日之旅 / Sol Cesto》做了一个免费开源的 QoL Mod：Fast Cesto。

它最初想解决的事情很简单：这款游戏的核心选择很有意思，但清理已经没有悬念的房间、重复演出和镜头拉近会消耗不少时间。Mod 做出来后，我自己长期使用了基础加速、关闭行动 Zoom、局外永久金币翻倍和 Shift 临时加速，确实明显改善了重开档时的体验。

公开 Alpha 发布后，一名真实用户告诉我“太好用了”，随后又提出了一个很具体的需求：第四区域的炸弹怪和手陷阱需要临时获得更多反应时间，能不能增加一个按住减速按钮？

这就是本次 `v0.2.0-alpha.1` 的主要更新。

#### 新功能：按住 Ctrl 临时减速

新版增加了 Focus（专注/临时减速）：

- 可选择左 Ctrl 或右 Ctrl；
- 目标速度可选 `0.5× / 0.75× / 1×`；
- 按住时临时减速，松开后立即恢复此前速度；
- 如果 Shift Turbo 和 Ctrl Focus 同时按住，Focus 优先；
- 松开 Ctrl 而 Shift 仍按住时，会重新回到 Turbo；
- 窗口失焦、挂起或读档后会清除临时状态，避免卡在加速或慢速。

例如我当前使用的配置是：平时 `1.5×`，按住 Shift 变为 `3×`，需要反应时按住 Ctrl 降到 `0.5×`。清场和思考可以用两套相反但互补的临时节奏。

第四区域不容易反复抵达，而且手陷阱计时结束会直接让角色死亡，所以我没有要求测试者反复打到那里送命。通过分析游戏原版事件和 Construct 运行时时钟，可以确认炸弹的 20 秒计时与手墙陷阱的 4.5 秒判定都使用缩放后的游戏时间。Focus `0.5×` 下，它们的现实反应窗口分别约为 40 秒和 9 秒，不是只把画面动画放慢。

#### 现有功能

Fast Cesto 当前包括：

- 基础速度：`1× / 1.25× / 1.5× / 2×`；
- 按住左/右 Shift 临时 Turbo；
- 按住左/右 Ctrl 临时 Focus；
- 可选关闭每次行动时反复出现的镜头 Zoom；
- 未来获得的局外永久金币可选 `1× / 2× / 3×`；
- 精确版本检查、自动原版备份、中断恢复和一键恢复原版；
- 离线本地界面，支持 English / 简体中文；
- 脱敏诊断，不上传文件、不联网、不读取或修改存档。

金币倍率只影响未来实际结算到局外账户的金币，不会凭空修改已有余额，也不会修改购买扣款、剧情奖励、概率或存档文件。

#### 已适配 Epic 1.01.4b

就在准备发布期间，Epic 版游戏更新到了玩家界面显示的 `1.01.4b`（归档内部项目版本为 `1.01.4`）。旧版 Mod 因为精确哈希保护，会把更新后的游戏识别为未知构建并拒绝修改；这是预期的安全行为。

我重新比较和测试了新版游戏：

- 16 种基础速度、Turbo、Focus 组合通过；
- 6 种 Zoom/金币组合通过；
- 20 个金币收入目标和唯一 Zoom 目标保持可验证；
- 炸弹和手墙陷阱计时链通过；
- 新版游戏可以正常加载 Mod；
- Ctrl Focus、Shift Turbo、两键重叠和失焦复位通过；
- 安装、恢复为新版原版、核对逐字节哈希、再次安装通过；
- 发布 ZIP 经过白名单检查，不包含任何游戏资源、EXE、DLL、存档、Epic 配置或本机凭据。

`v0.2.0-alpha.1` 只接受 Epic Windows `1.01.4b` 的精确构建。旧 `1.01.3`、Steam 版和其他未知哈希都会被拒绝，不会强行修改。Steam 版目前仍未支持，因为我没有 Steam 正版文件用于独立验证。

#### 下载与使用

GitHub Release：

https://github.com/liyan1775/fast-cesto/releases/tag/v0.2.0-alpha.1

下载文件：`fast-cesto-v0.2.0-alpha.1.zip`

SHA-256：

`34ED17AD0BA3C560D7B5B82D1E6120ED996FFB583E788474AF1F6AD1B83B6C0B`

使用前请注意：

1. 确认 Epic 游戏已经更新到 `1.01.4b`；
2. 由于 Epic 版没有云存档，请先自行备份存档；
3. 安装 Node.js 20 或更高版本；
4. 将 ZIP 完整解压到普通文件夹，不要直接在压缩包内运行；
5. 完全关闭游戏，双击 `start-fast-cesto.cmd`；
6. 查看十项兼容性检查，选择配置并应用；
7. 从 Epic Games Launcher 正常启动游戏。

不想继续使用时，关闭游戏，再次启动工具并选择“恢复原版”即可。工具使用的是从你自己的正版安装创建并校验的原版备份。

#### 这仍然是 Alpha

目前已有的验证足以确认新版兼容和核心补丁链路，但一台电脑无法覆盖所有 Windows、安装路径、DPI、安全软件和长局体验。Focus 的真实音频手感、暂停/切场景、特殊或死亡金币结算等仍欢迎反馈。

如果你愿意测试，请只描述系统版本、路径类型、测试结果和复现步骤，不要发送游戏文件、存档、Epic 配置、用户名或完整本机路径。

这是非官方社区项目，与游戏开发者和发行商无隶属、授权或背书关系；必须持有正版游戏。项目由我决定需求、功能和发布方向，并由 OpenAI Codex 协助研究、编程和自动化测试。
