## 2. 能否完全由 Codex 测试

不能完全由 Codex 测试，但首个可玩的内部原型的大部分客观验证可以由 Codex 完成。

Codex 可以独立完成：

- 文件、归档、补丁前后哈希和恢复；
- 自动化输入、截图和关键镜头 A/B；
- 多倍率的时序采样；
- 菜单、常见房间和异常状态的重复回归；
- 精确构建中的危险事件、倒计时/Tween、致死动作与 Construct 运行时时钟链审计；
- 未知版本拒绝、重复安装和中断恢复测试；
- 本机诊断包与 Release 包内容检查。

必须由用户判断：

- 1.5× 是否真正舒服，还是 1.25×/2× 更合适；
- 关闭 Zoom 是否减少不适，且没有让动作反馈变弱；
- 声音是否出现重叠、突兀或疲劳；
- 真实长 Run 是否仍有节奏、输入和选择问题；
- Epic Overlay、成就在用户正常启动方式下是否工作；
- 永久金币其他结算分支是否恰好 2×，以及该倍率是否符合长期节奏；
- 当前环境没有可用云存档时，本地恢复功能是否足够清晰。

公开发布前还必须有外部玩家测试，因为一台电脑无法证明不同 Windows、路径、DPI、安全软件和 Epic 环境的兼容性。

## 3. 给用户的接续试玩清单

当前安装目录已经处于内部 Alpha Turbo Preview 状态。正常金币 `2×`、基础加速和 Turbo 触发已完成首轮确认；接下来建议：

1. 从 Epic 正常启动，不使用调试参数；
2. 先玩 15–20 分钟，记录 1.5× 的主观感受；
3. 至少完成一次商店或特殊房间，并尽量到达一个 Boss；
4. 留意音频、快速点击、暂停、Alt+Tab 和返回菜单；
5. 检查 Epic Overlay/成就是否仍可用；
6. 在死亡、特殊离场或直接存入/出售发生时记录永久金币前后值，确认相应分支增加 `2N`；
7. 分别在按住 Turbo 时尝试暂停、切换房间/场景和 Alt+Tab，确认松键或失焦后回到基础 `1.5×`；
8. 退出后反馈长期金币节奏、Turbo 手感，以及奖励文本/动画是否与最终余额一致。

如出现异常，先不要让 Epic 验证游戏文件；记录发生场景和现象，再执行恢复。

## 4. 本机管理命令

在项目根目录执行：

```powershell
node tools\fast-cesto.mjs status SolCesto backups\epic-1.01.4b
node tools\fast-cesto.mjs restore SolCesto backups\epic-1.01.4b
node tools\fast-cesto.mjs install SolCesto config\fast-cesto.recommended.json backups\epic-1.01.4b

# 可选：启用左 Shift、2× 临时乘数的 Turbo 预览
node tools\fast-cesto.mjs install SolCesto config\fast-cesto.turbo-preview.json backups\epic-1.01.4b
```

`restore` 会恢复备份中经过哈希验证的原版；`install` 会从正版备份重新生成补丁，也可从已登记的内部 Alpha 状态安全切换配置。未知哈希一律拒绝。不要手工交换 `assets.dat`。

## 6. 发布门槛与渠道

| 阶段 | 渠道 | 必须满足 |
|---|---|---|
| 内部 Alpha | 本工作区 | 用户完整 Run、恢复成功、无 P0/P1 |
| 封闭 Alpha | GitHub Pre-release/受控链接 | 无游戏资源、3–5 台机器、未知版本拒绝 |
| 公开 Beta | GitHub | 安装说明、哈希、源码、已知问题、7–14 天观察 |
| Stable | GitHub + GameBanana | 跨机通过、恢复可靠、发布方态度或风险决定明确 |
| 后续 | Nexus/Steam 社区 | 有维护能力；Steam 版必须独立验证 |

公开包不得包含完整 `assets.dat`、游戏 EXE、Epic SDK、凭证或存档。权威下载源应是 GitHub；GameBanana 用于稳定版发现；Nexus 和 Steam 支持后置。

## 7. 当前决策

- 功能路线：**Go**；
- 测试路线：**部分可自动化，用户与外部测试不可省略**；
- 发布路线：**Conditional Go**，条件是先完成无版权资源的补丁器和最小跨机 Alpha；
- 当前公开 Alpha：`v0.1.0-alpha.2` 已发布；已有一名外部用户明确确认实际可用，但样本量仍不足以进入 Beta。
- 下一候选版本：`v0.2.0-alpha.1`，主功能为可选的按住减速（Focus）预览。
- 金币策略：倍率进入首版；一次性大量金币作为带备份和确认的后续恢复工具。
