# Security policy

## Supported version

Only the latest GitHub Alpha release is currently supported. Unknown Sol Cesto builds are deliberately rejected.

## Reporting a vulnerability

Do not open a public Issue for a vulnerability involving file overwrite, backup/restore integrity, local web UI access, command execution, or privacy leakage. Use GitHub's **Security → Report a vulnerability** form for this repository.

Do not attach game files, saves, Epic configuration, credentials, usernames, or full local paths. A minimal reproduction using synthetic files is preferred.

Ordinary compatibility or gameplay defects should use the public bug or Alpha-test Issue forms.
