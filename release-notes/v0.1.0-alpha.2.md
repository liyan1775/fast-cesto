# Fast Cesto v0.1.0-alpha.2 — bilingual UI update

This public Alpha fixes the interface-language omission reported after `alpha.1` testing.

## Changed

- Added a visible **English / 简体中文** selector at the top of the local interface.
- Uses the browser language on first launch and remembers the user's manual choice across reloads.
- Localized every static control, live installation status, all ten preflight checks, configuration summaries, confirmations, and operation results.
- Added automated translation-key parity, locale selection, structured preflight localization, static-server, and real-browser regression tests.

There is no game-patch behavior change from `alpha.1`: supported game hash, speed choices, Turbo, movement zoom, gold multiplier, backup, recovery, and restore behavior are unchanged. Existing `alpha.1` users may extract `alpha.2` to a new folder and run it; the tool will detect the current installed configuration.

> **Alpha warning:** only the exact Epic Windows `1.01.3` build is supported. Back up your save before testing. Unknown builds are rejected.

## Testers needed

Independent Windows 10/11 Epic installations are still needed, especially custom/non-ASCII paths, different DPI/security software, longer runs, special/death gold paths, and Turbo pause/scene/Alt+Tab coverage.

Use the repository's **Alpha test report** Issue form. Do not upload game files, saves, Epic configuration, usernames, or full local paths.
