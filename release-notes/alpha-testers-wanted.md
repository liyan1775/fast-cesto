Fast Cesto `v0.1.0-alpha.1` is now available for public testing.

Fast Cesto is a free, open-source, unofficial QoL mod for the exact Windows Epic Games Store `1.01.3` build of Sol Cesto. It provides configurable base speed, optional Shift Turbo, optional movement-camera zoom removal, and an optional multiplier for future permanent-gold income. It also includes exact build checks, verified backup/restore, transactional recovery, and privacy-filtered diagnostics.

This is an Alpha, not a stable release. Back up your save first. Steam and unknown hashes are rejected.

We need 3–5 independent test environments, especially:

- Windows 10 and Windows 11
- Epic default and custom install paths, including spaces or non-ASCII characters
- 100%, 125%, and 150%+ display scaling
- Windows Defender and third-party security software
- Longer runs, death/special gold paths, and Turbo during pause, scene transitions, and Alt+Tab

Please download the ZIP from the repository's pre-release, follow `ALPHA-TESTING.md`, and submit the **Alpha test report** Issue form.

Never upload game files, saves, Epic configuration, usernames, or full local paths. Inspect diagnostic JSON before attaching it.
