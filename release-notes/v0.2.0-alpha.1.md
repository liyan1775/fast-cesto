# Fast Cesto v0.2.0-alpha.1 — Focus and Epic 1.01.4b support

This Alpha updates Fast Cesto for the current Epic Games Store Windows `1.01.4b` build (internal project version `1.01.4`) and adds optional hold-to-slow Focus.

## What changed

- Added optional Focus on left or right Ctrl with absolute `0.5×`, `0.75×`, or `1×` target speed.
- Focus takes priority over Turbo; releasing Focus while Turbo is still held returns to Turbo speed.
- Blur, keyboard focus loss, suspend, and load clear temporary Turbo/Focus states.
- Added automatic schema v2 → v3 migration with Focus disabled for existing configurations.
- Updated exact-build support from the previous Epic `1.01.3` archive to the current Epic `1.01.4b` archive.
- Added English and Simplified Chinese Focus controls, summaries, diagnostics, a Focus preview preset, and expanded regression coverage.

## Compatibility and verification

Only this exact current Epic build is accepted:

- Epic client version: `1.01.4b`
- Internal project version: `1.01.4`
- Original `assets.dat` SHA-256: `3265599AE2CF79F650C22C33E56CE4DA83BF0655B24E67447208D3C7FAEEFC69`

The previous Epic `1.01.3` archive, Steam, and unknown hashes are rejected instead of being modified. Users who still need the old build can keep the historical `v0.1.0-alpha.2` release; do not force either release onto the wrong game build.

The updated build passed:

- 16 speed/Turbo/Focus patch combinations and 6 Zoom/gold combinations;
- exact checks for all 20 future permanent-gold income actions and the movement-Zoom action;
- fourth-area bomb and wall/hand-trap scaled-deadline audit;
- real WebView startup plus Ctrl Focus, Shift Turbo, overlap, release, and blur-reset input checks;
- install → exact original restore → reinstall;
- transaction recovery, preflight, bilingual UI, release allowlist, portable path, and release smoke tests.

## Alpha limits

Focus remains a preview feature. Longer runs, pause/scene-transition feel, real fourth-area audio/input feel, special/death gold paths, Windows 10, custom/non-ASCII paths, DPI variations, and third-party security software still need independent coverage.

Back up your save before testing; the Epic version does not provide cloud saves. This project does not redistribute game files, bypass DRM, edit saves, connect to the internet, or collect telemetry.
