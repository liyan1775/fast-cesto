# Fast Cesto v0.1.0-alpha.1 — public Alpha

This is the first public test release of Fast Cesto, an unofficial QoL mod for the Windows Epic Games Store version of Sol Cesto.

> **Alpha warning:** only the exact Epic Windows `1.01.3` build is supported. Back up your save before testing. Unknown builds are rejected.

## Included

- Configurable `1× / 1.25× / 1.5× / 2×` base speed
- Optional left/right Shift Turbo
- Optional movement camera-zoom removal
- Optional `1× / 2× / 3×` multiplier for future permanent-gold income
- Exact hash gating, automatic verified backup, transactional recovery, and restore
- Local-only configuration UI, ten compatibility checks, and privacy-filtered diagnostics

## Verified so far

- One real Epic `1.01.3` installation: install, launch, reconfigure, restore, and reinstall
- Base speed and movement-zoom behavior
- One normal permanent-gold settlement at `2×`
- Left-Shift Turbo activation in real gameplay
- Automated failure, recovery, UI, privacy, and release-bundle tests

## Testers needed

We need independent Windows 10/11 Epic installations, custom/non-ASCII paths, different DPI/security software, longer runs, special/death gold paths, and Turbo pause/scene/Alt+Tab coverage.

Use the repository's **Alpha test report** Issue form. Do not upload game files, saves, Epic configuration, usernames, or full local paths.
